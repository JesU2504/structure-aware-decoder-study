# Decision after reviewer-perspective assessment

earlier `NEXT_EXPERIMENT_2026-11-13.md` recommendation, which is preserved.

Read [the skeptical internal assessment](reviewer_perspective_2026-11-13/assessment.md).
It is not independent external peer review. New existing-data sensitivity checks
and projected-DEM screens pass; earlier artifacts and frozen-model failures remain
intact. More training helped, but underfitting has not been uniquely diagnosed.

The next step is a bounded validation gate: define a useful compiler decision,
use the existing data for the limited nonlinear/base/graph control, check timing
precision and old/new measurement context with a small bridge, and test one
decoder-configuration alternative with accuracy tracked. Freeze the comparison
before collecting balanced reserved-parent test data. No large training or
decoder-timing campaign has been launched by this review.

The study currently supports a restricted measurement and model-failure result,
not a demonstrated structure-aware compiler benefit. Continue that stronger
paper direction only if stable graph information changes useful fresh decisions
after accuracy, uncertainty, configuration, and modeling/profiling costs are
counted.
